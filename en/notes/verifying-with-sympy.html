Verifying with SymPy what the animations show

Diego E. Rodríguez V. · 4 min read

The verificar_*.py scripts behind the animations use NumPy and SciPy to check that the numbers in the video are right. That is a numerical check: it can miss a case you didn't try. SymPy checks the result exactly, with algebra, and Matplotlib draws the figures. Everything comes from one script: verificar_con_sympy.py.

1. The gradient is perpendicular to the level curve

The note on the gradient proves it with the chain rule. Here we check it on the example $f = \tfrac12(x^2 + 3y^2)$. The level curve $f = c$ is an ellipse parametrized by $\mathbf r(t) = \big(\sqrt{2c}\cos t,\ \sqrt{2c/3}\,\sin t\big)$.

grad = sp.Matrix([sp.diff(f, x), sp.diff(f, y)])
r = sp.Matrix([sp.sqrt(2*c)*sp.cos(t), sp.sqrt(2*c/3)*sp.sin(t)])
sp.simplify(f.subs({x: r[0], y: r[1]}) - c)               # 0: r(t) lies on f = c
sp.simplify(grad.subs({x: r[0], y: r[1]}).dot(r.diff(t)))  # 0: ∇f · r'(t)

Both lines return 0 for every $t$ and every $c > 0$, not just for a few test values. The same tool solves the zigzag inequality $|1 - 3\alpha| < 1$ and gives exactly $0 < \alpha < \tfrac23$.

2. The optimal can has h = 2r

For a fixed volume $V$, the sheet metal is $A(r) = 2\pi r^2 + 2V/r$. SymPy solves $A'(r) = 0$ and returns the optimal radius:

$$r^* = \left(\frac{V}{2\pi}\right)^{1/3}, \qquad \frac{h^*}{r^*} = 2.$$

The script checks that this ratio is exactly 2 and that $A''(r^*) > 0$, i.e. it is a minimum and not a maximum. For $V = 1000\ \text{cm}^3$ it gives $r^* \approx 5.42$ cm.

3. The Taylor polynomials of sin x

sp.series(sp.sin(x), x, 0, 10) returns the degree-9 polynomial, and the script compares it with the coefficients used in the animation:

$$\sin x \approx x - \frac{x^3}{6} + \frac{x^5}{120} - \frac{x^7}{5040} + \frac{x^9}{362880}.$$

What this proves and what it doesn't

SymPy checks the algebra of these specific cases. It doesn't replace the general proof: perpendicularity holds for any differentiable $f$, and here we only verify one example.
